# --- PRUEBAS DE ERRORES LÉXICOS Y SINTÁCTICOS (Estilo Python) ---

# 1. Error léxico (carácter no reconocido por el lexer)
# precio = 10 & 5

# 2. Error sintáctico: Falta de dos puntos (:) en la definición de función
def sumar(a, b)
    return a + b

# 3. Error sintáctico: Expresión mal formada (operador seguido de operador sin operando)
x = 10 + * 5

# 4. Error sintáctico: Lado izquierdo de asignación no válido (asignar a un literal)
10 = y

# 5. Error sintáctico: Un 'else' sin un 'if' previo
else:
    y = 0

# 6. Error sintáctico: Bloque con indentación incorrecta o faltante
if x > 5:
x = x + 1
